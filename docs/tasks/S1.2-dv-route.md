## Background (do not re-research)
- Telnyx calls POST /dv when a call starts. The body is JSON: { "data": { "event_type": "assistant.initialization", "payload": { "telnyx_end_user_target": "+61...", "call_control_id": "v3:...", "assistant_id": "..." , ... } } }. Headers: telnyx-signature-ed25519 (base64) and telnyx-timestamp.
- The response must be { "dynamic_variables": { ... } } with ALL values strings. A flat object is silently ignored by Telnyx.
- Secrets reach a function as environment variables injected at deploy time (documented form in TypeScript: process.env.NAME). A plain env.NAME is not documented. Whether process.env exists in the umbrella runtime is UNVERIFIED, so read config through the helper below, which tries both. Never print or log a secret value.
- The handler must stay fast (target under 1000 ms) and make no external calls: KV reads only.

## Spec: src/routes/dv.ts
export interface DvEnv { DISPATCH_KV: { get(key: string): Promise<string | null> }; [key: string]: unknown }
(Make the KV part match how the real binding's get is called, so src/index.ts can pass its real env; check node_modules/@telnyx/edge-runtime type declarations. tsc must pass.)

export async function handleDv(request: Request, env: DvEnv, nowMs: number = Date.now()): Promise<Response>

Behaviour, in order:
1. request_id = newRequestId(). start a timer for latency.
2. If method is not POST: respond 405 { ok:false, error:"method_not_allowed" }.
3. rawBody = await request.text() (read once). Log event "dv_in" (component "dv", request_id, no phone, no body).
4. Public key = readConfig(env, "TELNYX_PUBLIC_KEY"). If missing: respond 403 { ok:false, error:"forbidden" } and log level "error", event "sig_fail", outcome "rejected", error "no_public_key".
5. result = await verifyTelnyx(rawBody, request.headers.get("telnyx-signature-ed25519"), request.headers.get("telnyx-timestamp"), publicKey, nowMs). If not ok: respond 403 { ok:false, error:"forbidden" } (same body for every reason) and log level "warn", event "sig_fail", outcome "rejected", error = the reason string.
6. Parse JSON from rawBody inside try/catch. Read payload = parsed.data.payload with optional chaining; phone = payload.telnyx_end_user_target if it is a string; call_ref = payload.call_control_id if it is a string, else "unknown".
7. Salt = readConfig(env, "LOG_SALT"). If both phone and salt exist, caller_hash = await callerHash(phone, salt). If salt is missing, caller_hash stays unset (never log the phone).
8. Build variables, inside a try/catch for the whole lookup:
   - dispatch_enabled: read env.DISPATCH_KV.get(keys.flag("dispatch_enabled")); the value is "false" only if the stored string is exactly "false"; anything else (including null/missing) gives "true".
   - customer: if phone exists, read env.DISPATCH_KV.get(keys.customer(phone)); if a string, JSON.parse it in its own try/catch (parse failure: treat as not found and log level "warn", event "dv_bad_customer_record"). Expected record shape: { customer_id, name, address, site_notes, after_hours_contract }.
   - Output (every value a string):
     call_ref, business_name ("Harbour Trades After-Hours", a constant at the top of the file), caller_known ("true" if a record was found else "false"), customer_name (record.name or ""), customer_address (record.address or ""), dispatch_enabled, fallback_number_spoken (a constant at the top of the file: "zero four nine one, five seven zero, one five six", with a TODO comment to replace it with the real escalation number), hold_ttl_s (readConfig(env, "DISPATCH_HOLD_TTL_S") or "90").
9. If anything in step 6 to 8 throws (KV error or bad JSON): respond 200 with the SAFE DEFAULTS: dispatch_enabled "true", caller_known "false", customer_name "", customer_address "", call_ref as known or "unknown", plus the constants; log level "warn", event "dv_degraded", outcome "degraded", error = a short message. The call must always proceed.
10. Success: respond 200 JSON { "dynamic_variables": { ... } } (top-level key is exactly dynamic_variables, content-type application/json). Log event "dv_out" with outcome "ok" (or "degraded" in the degraded case), call_ref, caller_hash if present, latency_ms from the timer.
Use log() from src/lib/log.ts for every log line. Never log the body, the phone number, the signature or any secret.

## Spec: scripts/sign.ts (run by the human with `npx tsx scripts/sign.ts <command>`)
This script is for local and live testing only. Plain Node, no dependencies beyond built-ins.

If the file exists, print the public key from it. Never print the private key.
- `curl <base-url> [phone] [--tamper] [--stale] [--unsigned]`: print (do not run) a ready-to-paste curl command for POST <base-url>/dv with a sample assistant.initialization body (phone default "+61491570006", call_control_id "v3:sim-test-001"), headers telnyx-signature-ed25519 and telnyx-timestamp (Unix seconds, now) signed with the test private key over `${timestamp}|${body}`. --tamper changes one character of the body after signing; --stale sets the timestamp 10 minutes in the past (and signs for it); --unsigned omits both headers. Use single quotes around the body so it is paste-safe.

10. Privacy: with LOG_SALT set, no captured log output contains "61491570006" and the dv_out line has a 12-character hex caller_hash; with LOG_SALT missing, caller_hash is null.
