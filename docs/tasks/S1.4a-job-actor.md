## Record (one storage key "job")
{ call_ref, job_id, tech_id, state: "reserved" | "briefed" | "released", urgency, trade, suburb, summary, customer_name?, address?, contact_phone?, details?, hazards?, release_reason?, created_at, updated_at }
call_ref is this.ctx.id (fall back to "call" when the fake ctx has no id). Never mutate the object read from storage; build a new object before put. Times are epoch ms.

## JobActor methods (plain-data args and returns; no method name starting with "_" except private helpers)
- open({ job_id, tech_id, urgency, trade, suburb, summary }) -> { ok:true, state, created:boolean } | { ok:false, reason:"invalid_input" | "job_mismatch" | "already_closed" }
  invalid_input if any field is not a non-empty string. No record: store state "reserved", created:true. Record with the same job_id: state released -> already_closed; otherwise ok:true, created:false, no write. Record with a different job_id -> job_mismatch.
- brief({ job_id, customer_name, address, contact_phone?, details, hazards? }) -> { ok:true, state:"briefed" } | { ok:false, reason:"invalid_input" | "no_active_reservation" }
  invalid_input if customer_name, address or details is not a non-empty string, or contact_phone / hazards is present but not a string. No record, a different job_id, or state released -> no_active_reservation. State reserved or briefed -> store the fields, state "briefed" (replaying is allowed).
- release({ job_id, reason }) -> { released: boolean }
  true only if the record has this job_id and state reserved or briefed; then state "released" and release_reason stored. Anything else false; never throws.
- get() -> the record or null.
