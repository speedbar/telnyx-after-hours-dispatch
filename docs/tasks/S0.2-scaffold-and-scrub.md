## scripts/scrub-sdk-examples.mjs spec
Plain Node ESM, no dependencies, Node 18+, must work on macOS and Linux.
- Why (put in a header comment): Telnyx's server-side secret scanner rejects `telnyx-edge ship` with HTTP 422 ("looks like a secret", generic-api-key) because of example values inside the bundled `telnyx` SDK. See docs/bug-journal.md BUG-001.
- Targets: every directory named `telnyx` under node_modules (top level and nested, for example node_modules/@telnyx/edge-runtime/node_modules/telnyx) whose package.json name is "telnyx". Do not follow symlinks.
- Files: .js .mjs .cjs .ts .mts .cts inside those directories.
- Replacements, with the patterns as named constants at the top of the file:
  (a) any UUID that starts with `182bd5e5-` becomes `EXAMPLE`;
  (b) any UUID inside quotes right after `token_group_id` followed by `:` or `=` becomes `EXAMPLE`;
  (c) `tskey-auth-` followed by [A-Za-z0-9_-]+ becomes `tskey-auth-EXAMPLE`.
- Write a file only if its content changed.
- Normal mode prints one summary line "scrub-sdk-examples: N file(s) changed, M replacement(s)" and lists the changed paths. It is idempotent: a second run reports 0 and 0.
- Normal mode never exits non-zero (postinstall must not break npm install): catch errors and warn. If no telnyx SDK is found, print "telnyx SDK not found, nothing to scrub" and exit 0.
- `--check` mode changes nothing. It prints file:line (never the matched value) for every remaining match and exits 1, or prints "clean" and exits 0.
