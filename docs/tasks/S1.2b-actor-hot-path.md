## Why

## src/actors/DirectoryActor.ts
export class DirectoryActor extends StatefulActor (same import as TechnicianActor). Storage keys reuse the helpers in src/lib/kv-keys.ts (keys.flag, keys.customer) so the key names match KV.
- async lookup(phoneDigits: string, flagName: string): Promise<{ flag: string | null; customer: string | null }>
  One storage get for keys.flag(flagName) and one for keys.customer("+" + phoneDigits) (customer() strips the plus). Return raw strings, no parsing. Do both reads in parallel with Promise.all.
- async seed(entries: Array<{ key: string; value: string }>): Promise<number>
  assertValidKey each key, storage.put each, return the count. Reject (throw) on an invalid key before writing anything.
Keep both methods tiny; no caching, no TTL.

## src/routes/dv.ts changes
- Replace the two KV gets with ONE call: stub = env.DIRECTORY.idFromName("directory"); await stub.lookup(phoneDigits, "dispatch_enabled") where phoneDigits is the phone with "+" removed (skip the call when there is no phone and use flag default "true"; then still call lookup with an empty-safe path: if no phone, call it with "0" so the flag still resolves).

On timeout or any error keep the existing degraded behaviour (200, safe defaults, dv_degraded, outcome degraded). Set error to "lookup_failed:" + err.name, except the timeout, whose error is exactly "lookup_timeout".
- Add one log event after the lookup: event "dv_lookup", component "dv", tool "actor.lookup", latency_ms = time taken, outcome "ok" or "error". Use the existing timed helper if it fits.
- The rest (signature checks, variable names, string values, privacy rules, hold_ttl_s) is unchanged.
- DvEnv: replace DISPATCH_KV with DIRECTORY: { idFromName(name: string): DirectoryStub } where DirectoryStub = { lookup(phoneDigits: string, flagName: string): Promise<{flag: string|null; customer: string|null}> }.

## src/routes/seed.ts and the /admin/seed route
export async function handleSeed(request: Request, env: SeedEnv): Promise<Response>
- POST only (405 otherwise). Token: header x-admin-token must equal readConfig(env, "ADMIN_TOKEN") (compare in constant time, same length check first). Missing secret or mismatch: 403 { ok:false, error:"forbidden" } and log event "seed_fail" (warn). Never log the token.
- Body JSON: { "customers": [ { "phone": "+614...", "record": { ... } } ], "flags": { "dispatch_enabled": "true" } }. Validate shape; 400 { ok:false, error:"bad_body" } if wrong.
- Build entries: keys.customer(phone) -> JSON.stringify(record); keys.flag(name) -> value. Write them to the DirectoryActor with seed(). Then, as a second step, write the same entries to KV (env.DISPATCH_KV.put) one at a time; if a KV put fails, keep going and report it. KV is slow (about 2 s each) so this route may take several seconds; that is fine.
- Response 200: { ok:true, actor_count: n, kv_ok: n, kv_failed: n }. Log one "seed_done" event with those counts. Never log phone numbers or record contents.
- In src/index.ts: `/admin/seed` calls handleSeed(req, { ...env }) with the same spread pattern as /dv.
