# Task S1.0: KV key helper and a test runner

Read AGENTS.md first (see "Platform facts" and "Conventions"). Do this task and nothing else.

## Why
The KV service accepts only these key characters: a-z A-Z 0-9 - _ / = . (BUG-002, decision D10). Every key in the project must be built by one validating helper so a bad key can never reach the service.

## Files
- src/lib/kv-keys.ts (new)
- tests/kv-keys.test.ts (new)
- package.json: add ONE script only: "test": "tsx --test tests/*.test.ts". Change nothing else in package.json. No new dependencies.

## Spec for src/lib/kv-keys.ts (pure functions, no imports, no KV access)
- export const KEY_PATTERN = /^[A-Za-z0-9\-_\/=.]+$/
- export function sanitizeSegment(input: string): string
  Replace every character outside [A-Za-z0-9\-_=.] with "_" (this includes "/", ":", "+", spaces). If the result is empty, throw new Error("invalid_kv_segment").
- export function assertValidKey(key: string): string
  Return the key if it matches KEY_PATTERN, otherwise throw new Error("invalid_kv_key"). Do not enforce a maximum length (the service limit is unknown; leave a TODO comment saying VERIFY).
- export const keys = {
    flag: (name: string) => "flag/" + sanitizeSegment(name),
    customer: (e164: string) => "cust/" + sanitizeSegment(e164.replace(/^\+/, "")),
    job: (jobId: string) => "job/" + sanitizeSegment(jobId),
    jobByCall: (callRef: string) => "job-by-call/" + sanitizeSegment(callRef),
  }
  Every function in keys must pass its result through assertValidKey before returning.

## Tests (tests/kv-keys.test.ts, use node:test and node:assert, no other libraries)
1. keys.flag("dispatch_enabled") equals "flag/dispatch_enabled".
2. keys.customer("+61412345678") equals "cust/61412345678".
3. keys.job("JA47") equals "job/JA47".
4. keys.jobByCall("v3:abc-123") equals "job-by-call/v3_abc-123" (colon replaced).
5. sanitizeSegment("a/b c+d") equals "a_b_c_d" (slash, space and plus replaced; a "/" inside a segment must never create a new path level).
6. sanitizeSegment("") throws; assertValidKey("kvtest:ping") throws; assertValidKey("kvtest/ping") returns "kvtest/ping".
7. Every value produced in tests 1 to 4 matches KEY_PATTERN.
