## handleMcp(request, env, registry = TOOLS)
Order of checks, each returning application/json:
1. Method must be POST, else 405 { ok:false, error:"method_not_allowed" } with an Allow: POST header.
2. Auth. Accept the key as `Authorization: Bearer <token>` or as an `x-api-key: <token>` header. Compare in constant time (tokenEqual from ./seed) with readConfig(env, "MCP_TOKEN"). Missing, wrong or unconfigured -> 401 { ok:false, error:"unauthorized" } with a WWW-Authenticate: Bearer header, and log { component:"mcp", event:"auth_fail", level:"warn", outcome:"rejected", request_id, error: "no_token_configured" | "no_auth_header" | "bad_token" }. Never log a header value. The error string only says which case it was.
3. Read the body as text; over 32768 characters -> 413 { ok:false, error:"too_large" }. Invalid JSON -> 400 with a JSON-RPC error -32700 (id null). A JSON array (batch) or anything that is not an object with jsonrpc "2.0" and a string method -> 400 with -32600.
4. A message with no id is a notification: return 202 with an empty body, whatever the method (this covers notifications/initialized).
5. Methods:
   - initialize -> result { protocolVersion: params.protocolVersion if it is a string, else "2025-03-26", capabilities: { tools: {} }, serverInfo: { name: "dispatch-mcp", version: "0.1.0" } }.
   - ping -> result {}.
   - tools/list -> result { tools: registry.map(t => ({ name, description, inputSchema })) }.
   - tools/call -> params.name must be a string naming a registry tool, else a JSON-RPC error -32602 with message "unknown_tool". Run the handler with params.arguments (default {}) inside timed() from src/lib/log.ts. Success (including business failures with ok:false) -> result { content: [{ type:"text", text: JSON.stringify(output) }], isError: false }. If the handler throws -> result { content: [{ type:"text", text: JSON.stringify({ ok:false, error:"internal" }) }], isError: true }; never put the exception message or a stack in the response.
   - anything else -> JSON-RPC error -32601.
   Success envelope { jsonrpc:"2.0", id, result }; error envelope { jsonrpc:"2.0", id, error:{ code, message } }. JSON-RPC protocol errors use HTTP 200 except the 400s above.
6. Log one line per tools/call: { component:"mcp", event:"mcp_call", tool: name, request_id, latency_ms, outcome: "ok" when output.ok is true, "rejected" when output.ok is false, "fail" when the handler threw; call_ref only if the argument is a string that passes isCallRef; job_id only if the output has a string job_id; error = output.reason when rejected, or the exception name when failed }. If latency_ms > 500 use level "warn" and, when no other error text is set, error "over_budget". Never log arguments, names, addresses or phone numbers.
Type the env as ToolEnv & { [key: string]: unknown } so tsc passes without regenerating telnyx-env.d.ts.
