## TechnicianActor methods (plain-data args and returns; no method name starting with "_")
- reserve({ call_ref, job_id, ttl_s }) -> { ok: true, expires_at } | { ok: false, reason: "busy" | "off_shift" | "invalid_input" }
  invalid_input if call_ref or job_id is not a non-empty string or ttl_s is not an integer 1..600 (default 90 when ttl_s is undefined).
  First expire an old hold if expires_at <= now. off_shift -> off_shift. Held by the SAME call_ref -> ok:true with the existing expires_at (idempotent). Held by another call_ref -> busy. Otherwise store the hold, set status "held", set an alarm at expires_at.
- release({ call_ref, job_id }) -> { released: boolean }
  true only if a live hold matches both call_ref and job_id; then status "available", hold cleared, alarm deleted. Anything else false, never throws.
- status() -> the state after lazily expiring an old hold.
- setShift(on: boolean) -> state. on=false sets off_shift and clears any hold; on=true sets available (clears any hold). Used for tests and the demo.
- alarm(): if a hold exists and has expired, clear it and log event "hold_expired"; if a live hold remains, re-arm the alarm for its expiry. Idempotent: safe to run twice.
Alarm API: check node_modules/@telnyx/edge-runtime type declarations for the real names (setAlarm / deleteAlarm / alarm). If alarms are missing from the types, implement the lazy expiry only and say so in your final summary.
Log with log() from src/lib/log.ts, component "actor", fields technician_id (= state.id), job_id, attempt not needed. Events: "reserve_attempt" (outcome ok or rejected), "release" (outcome ok), "hold_expired". Never log phone numbers.
