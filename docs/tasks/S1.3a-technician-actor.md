## State (one storage key "state")
{ id: string, status: "available" | "held" | "off_shift", held_for?: { call_ref: string, job_id: string, expires_at: number }, updated_at: number }
A missing state means { id: <ctx.id or "tech">, status: "available", updated_at: 0 }. expires_at is epoch ms.
Read once per method through a private helper whose name starts with "_" (not RPC-exposed). The helper lazily clears an expired hold in memory and does not write; the calling method writes at most once.

## Methods (plain-data args and returns)
- reserve({ call_ref, job_id, ttl_s }) -> { ok: true, expires_at } | { ok: false, reason: "busy" | "off_shift" | "invalid_input" }
  invalid_input if call_ref or job_id is not a non-empty string or ttl_s is not an integer 1..600 (default 90 when ttl_s is undefined).
  An expired hold counts as no hold. off_shift -> off_shift. Held by the SAME call_ref -> ok:true with the existing expires_at (idempotent, no write). Held by another call_ref -> busy. Otherwise store the hold, status "held", setAlarm(expires_at).
- release({ call_ref, job_id }) -> { released: boolean }
  true only if a live hold matches both call_ref and job_id; then status "available", hold cleared, deleteAlarm(). Anything else false, never throws.
- status() -> the state after lazily expiring an old hold (write only if something expired).
- setShift(on: boolean) -> state. on=false sets off_shift and clears any hold; on=true sets available (clears any hold). Delete the alarm when a hold is cleared.
- alarm(_info?): if a hold exists and has expired, clear it and log "hold_expired"; if a live hold remains, re-arm setAlarm(expires_at). Idempotent.
